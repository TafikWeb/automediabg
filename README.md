# AutoMediaBG — сайт + админ панел + Telegram известия

## Какво съдържа проектът
- Публичен сайт (`/`) — динамичен, продуктите и галерията се управляват от админ панела.
- Заявки от формата се записват в SQLite база и незабавно пращат съобщение в Telegram.
- Админ панел на `/admin` — продукти, галерия снимки, лого, преглед на заявки.
- Опционален Telegram бот (`bot.py`) с команди `/leads` и `/stats`.
- Логото ти вече е сложено в `data/uploads/logo/logo.png`.

## 1. Локално стартиране в VS Code (за да провериш, че работи)

Отвори папката `automediabg-backend` във VS Code, отвори вграден терминал (`` Ctrl+` ``) и изпълни:

```bash
python3 -m venv venv
source venv/bin/activate          # На Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
```

Отвори `.env` във VS Code и попълни:
- `SECRET_KEY` — произволен дълъг низ (просто напечатай нещо случайно)
- `ADMIN_USERNAME` / `ADMIN_PASSWORD` — с каквото искаш да влизаш в `/admin`
- `DATA_DIR` — за локално тестване изтрий реда или го смени на `./data`

Стартирай:
```bash
python app.py
```

Отвори `http://localhost:5000` в браузър — трябва да видиш сайта с логото.
Отиди на `http://localhost:5000/admin/login` и влез с данните от `.env`.

Ако всичко работи локално, спри сървъра (`Ctrl+C`) и продължи към деплой.

## 2. Деплой в Railway — стъпка по стъпка

### А) Качи кода в GitHub (Railway чете от там)
1. Създай нов repository в GitHub (например `automediabg-site`), без README/gitignore (вече ги имаш).
2. В терминала на VS Code, в папката на проекта:
   ```bash
   git init
   git add .
   git commit -m "Първи commit"
   git branch -M main
   git remote add origin https://github.com/ТВОЯ-АКАУНТ/automediabg-site.git
   git push -u origin main
   ```
   (`.env` и `data/` **няма** да се качат — те са в `.gitignore` нарочно, защото съдържат тайни данни и локални файлове.)

### Б) Създай проект в Railway
1. railway.app → New Project → **Deploy from GitHub repo** → избери repo-то.
2. Railway автоматично разпознава Python проект (заради `requirements.txt` и `Procfile`) и започва build.

### В) Добави Volume (ЗАДЪЛЖИТЕЛНО — иначе губиш данни при всеки deploy)
1. В проекта в Railway → Settings → **Volumes** → Add Volume.
2. Mount path: `/app/data`
3. Това е мястото, където ще живеят базата данни и качените снимки/лого постоянно.

### Г) Добави Environment Variables
В Railway → Variables, добави същите неща като в `.env.example`:
```
SECRET_KEY=нещо-дълго-и-случайно
ADMIN_USERNAME=admin
ADMIN_PASSWORD=твоя-парола
TELEGRAM_BOT_TOKEN=(виж стъпка 3 по-долу)
TELEGRAM_CHAT_ID=(виж стъпка 3 по-долу)
DATA_DIR=/app/data
```

### Д) Качи логото и данните наново
Понеже `data/` не се качва в GitHub, след първия deploy трябва:
1. Отвори публичния URL, който Railway ти дава (Settings → Networking → Generate Domain).
2. Влез в `/admin/login`.
3. Качи логото през `/admin/logo` (файлът вече е готов локално в `data/uploads/logo/logo.png` — просто го качи през същата форма на живия сайт).
4. Добави продукти и снимки от галерията.

Railway ще пресъздава контейнера при всеки нов deploy, но Volume-а на `/app/data` остава — така нищо не се губи.

## 3. Настройка на Telegram известия (5 минути)

1. Отвори Telegram → **@BotFather** → `/newbot` → дай име (напр. `AutoMediaBG Bot`).
   Ще получиш **токен** — сложи го в Railway Variables като `TELEGRAM_BOT_TOKEN`.
2. Отвори чат с новия бот и му прати каквото и да е съобщение (за да се "активира").
3. За да намериш своя `chat_id`, отвори в браузър:
   `https://api.telegram.org/bot<ТВОЯ_ТОКЕН>/getUpdates`
   и виж числото в `"chat":{"id": ...}`.
4. Сложи го в Railway Variables като `TELEGRAM_CHAT_ID`. Redeploy (или просто изчакай — Railway рестартира автоматично при промяна на variables).

При нова заявка от сайта ще получаваш съобщение директно в Telegram.

**Защо Telegram, а не Viber:** безплатно е и отнема 5 минути. Viber изисква одобрен Business акаунт — може да се добави по-късно.

## 5. Тестване на телефон, преди да пуснеш сайта на живо

Най-лесният начин — пускаш сайта локално и го отваряш от телефона през домашния Wi-Fi:

1. Стартирай сайта локално както обикновено (`python app.py`).
2. Намери локалния IP адрес на компютъра си:
   - Windows: отвори `cmd`, напиши `ipconfig`, търси "IPv4 Address" (обикновено нещо като `192.168.0.105`)
   - Mac/Linux: `ifconfig` или `ip addr`, търси адрес започващ с `192.168.` или `10.`
3. На телефона (свързан към **същия Wi-Fi**) отвори браузър и въведи:
   `http://ТВОЯ-IP:5000` (напр. `http://192.168.0.105:5000`)
4. Готово — виждаш живия сайт на телефона, с всички промени в реално време докато го редактираш.

Ако искаш да тестваш и извън домашната мрежа (напр. през мобилни данни) преди да хостваш истински — може да ползваш **ngrok** (безплатно): изтегляш от ngrok.com, пускаш `ngrok http 5000` докато `python app.py` работи, и той ти дава временен публичен адрес (`https://xxxx.ngrok-free.app`), който препраща към компютъра ти.

## 6. Сигурност — какво вече е защитено и какво да внимаваш

**Вече вградено в кода:**
- **CSRF защита** — всички формуляри в админ панела имат скрит токен, който пречи на злонамерен сайт да изпраща скрити заявки (напр. "изтрий всички продукти") от името на влезлия админ.
- **Ограничение на опитите за вход** — след няколко неуспешни опита за парола на `/admin/login`, системата временно блокира допълнителни опити (пречи на brute-force атака за отгатване на паролата).
- **Сигурна session бисквитка** — маркирана да не е достъпна от JavaScript (пречи на XSS кражба на сесия) и да се изпраща само през HTTPS в production.
- **SQL injection защита** — цялата работа с базата минава през SQLAlchemy ORM, а не през ръчно съставени SQL заявки, така че класическите SQL injection атаки не важат тук.
- **Ограничени типове и размер на файлове** — само png/jpg/webp се приемат за качване, с лимит от 60MB на заявка.

**Какво трябва ти да направиш:**
- **Силна парола** за `ADMIN_PASSWORD` в `.env` (не нещо предвидимо като "admin123").
- **HTTPS** — Railway го осигурява автоматично за твоя домейн, не е нужно нищо допълнително.
- **Пази `.env` и `data/` извън GitHub** — вече са в `.gitignore`, но провери, че никога не ги качваш ръчно.
- **Редовен backup на базата данни** — Railway Volume пази данните между deploy-и, но не е автоматичен backup срещу случайно изтриване. Можеш периодично (напр. веднъж месечно) да свалиш `automediabg.db` от Volume-а през Railway CLI и да го пазиш отделно.
- **Смени `TELEGRAM_BOT_TOKEN`**, ако някога случайно се появи в скрийншот, чат или публично място — токенът дава пълен достъп до бота ти.

## 7. Telegram общност и реферална програма за отстъпки

Това е отделен бот (`bot_community.py`) от бота за известия. Той посреща нови хора в Telegram групата ти, обяснява как се получава отстъпка, и пази всичко в базата данни (виждаш го в `/admin/telegram`).

**Честно за какво Telegram реално позволява:**
- ✅ Ботът МОЖЕ реално да провери дали някой е в Telegram групата ти (истинска проверка, не почетна дума).
- ⚠️ Instagram (следва ли ни) и Viber (влязъл ли е в групата) **нямат публично API** за проверка на трети страни — Telegram/Viber/Instagram не позволяват на бот да "погледне" дали конкретен човек следва профил или е в чужда група. Затова тези две отметки са на "потвърждавам сам" бутон в бота. Ако имаш съмнение за конкретен клиент, можеш ръчно да смениш отметката от `/admin/telegram`.
- ⚠️ Бот **не може да пише пръв** на потребител, който не е стартирал чат с него преди това — това е ограничение на Telegram, не бъг. Затова новите участници получават съобщение В групата с бутон, който сами трябва да натиснат, за да се отвори личен чат с бота.

### А) Създай бота в BotFather
1. Telegram → **@BotFather** → `/newbot` → дай име (напр. `AutoMediaBG Community Bot`).
2. Копирай токена → сложи го в `.env` / Railway Variables като `TELEGRAM_COMMUNITY_BOT_TOKEN`.

### Б) Създай Telegram групата (ако още нямаш)
1. Telegram → New Group → покани поне себе си, дай име (напр. "AutoMediaBG Club").
2. Добави новия бот в групата, направи го **администратор** (Settings → Administrators → Add Admin) — без права на админ ботът не може да проверява членство и да праща съобщения в групата надеждно.
3. Вземи `chat_id` на групата: пусни `bot_community.py` (виж стъпка Г по-долу), после в самата Telegram група напиши `/groupid` — ботът ще ти отговори директно с числото (напр. `-1001234567890`). Сложи го в `.env` като `TELEGRAM_GROUP_ID` и рестартирай бота.
4. По желание — сложи `SITE_URL` в `.env` (адреса на живия сайт), за да може бота да дава линк към продуктите в менюто "Продукти".
4. Направи покана линк за групата (Group Info → Invite Link) и го сложи в `/admin/links` при "Telegram група".

### В) Свържи Viber/Instagram линковете
Отвори `/admin/links` в сайта и попълни реалните линкове към Instagram профила и Viber групата — ботът ги чете директно от там (същите линкове, които виждаш и на сайта).

### Г) Пусни бота
Локално за тест:
```bash
pip install aiogram==3.7.0
python bot_community.py
```
На Railway — виж стъпка 8 по-долу за пускане като отделен процес.

### Д) Как работи за клиента
1. Влиза в Telegram групата → бота (като админ) праща поздрав В ГРУПАТА с бутон "Отвори бота 🎁".
2. Клиентът натиска бутона → отваря се личен чат с бота → вижда меню с 2 опции: "📩 Заявка/Въпрос" и "🎁 Отстъпка".
3. При "Отстъпка" вижда чеклиста (Instagram/Viber/Telegram/3 покани), с бутони към всяка стъпка и бутон "Потвърждавам".
4. Получава личен линк за покани (`t.me/твоя_бот?start=ref_ID`) — когато приятел влезе през него, автоматично се брои.
5. След монтаж, клиентът праща снимка директно в чата с бота → тя ти идва лично в Telegram (на `TELEGRAM_CHAT_ID`), а профилът на клиента се отбелязва.
6. При "Заявка/Въпрос" — каквото напише, идва директно при теб в Telegram.

Всичко се вижда в `/admin/telegram` — с колко процента отстъпка е изкарал всеки, брой покани, и статус на всяка стъпка.

## 8. Пускане на два процеса на Railway (сайт + бот)

Railway поддържа няколко услуги (services) от един и същ repo. За да работят сайтът и `bot_community.py` едновременно:

1. В Railway проекта → **New Service** → **GitHub Repo** → избери същия repo отново (ще стане втора услуга).
2. За новата услуга, в Settings → Deploy → **Custom Start Command**, сложи:
   ```
   python bot_community.py
   ```
3. Добави същите Environment Variables като на основната услуга (най-лесно: копирай ги) — важно е `DATA_DIR` да сочи към **същия Volume mount path** (`/app/data`), за да чете и пише в същата база данни като сайта.
4. Ако искаш и `bot.py` (ботът за известия с `/leads` `/stats` команди) — е трета услуга по същия начин, по избор.

Ботовете трябва да работят постоянно (за разлика от сайта, който отговаря само при заявка) — Railway ги държи "живи" автоматично, стига да не гръмнат с грешка.

## 9. SEO, Google Analytics, GDPR и компресия на снимки

Тези неща вече са вградени, само трябва да ги активираш/провериш:

**SEO основи (готово автоматично):**
- Заглавие и описание за Google вече са зададени в `<title>`/`<meta description>` в `templates/index.html` — редактирай ги там, ако искаш да ги промениш.
- Favicon-ите вече са генерирани от логото ти (`static/favicon.png` и другите размери).
- `/sitemap.xml` и `/robots.txt` работят автоматично — след като хостнеш, провери ги на `твоя-домейн/sitemap.xml`.
- Препоръка: качи сайта в [Google Search Console](https://search.google.com/search-console) и подай sitemap-а, за да започне Google да го индексира по-бързо.

**Google Analytics (по избор):**
1. Направи GA4 профил на [analytics.google.com](https://analytics.google.com), вземи Measurement ID (формат `G-XXXXXXXXXX`).
2. Сложи го в Railway Variables (или `.env` локално) като `GOOGLE_ANALYTICS_ID`.
3. Готово — скриптът се зарежда автоматично, но **само след като посетител натисне "Приемам"** на банера за бисквитки (виж по-долу).

**GDPR / бисквитки (готово автоматично):**
- Долу вдясно на сайта се появява банер за бисквитки при първо посещение, с бутони "Приемам"/"Отказвам".
- Google Analytics се зарежда само при "Приемам" — при "Отказвам" изобщо не се стартира (истинско, не декоративно съгласие).
- Страница `/privacy` с политика за поверителност — линк към нея е в футъра на сайта. Прегледай текста и го редактирай в `templates/privacy.html`, ако искаш да добавиш нещо специфично за бизнеса ти.

**Компресия на снимки (готово автоматично, без настройка):**
- Всяка нова снимка, качена през админ панела (продукти, галерия, лого), автоматично се смалява (максимум 1920px по дългата страна за продукти/галерия) и се компресира — в тестове намалих файл от ~190KB на ~16KB (91% по-малко) без забележима загуба на качество.
- Логото пази прозрачност (PNG), само се смалява ако е прекалено голямо.
- Не е нужно да правиш нищо — просто качваш снимки нормално, компресията е автоматична отзад.

## 10. Бутон "Вземи 5% отстъпка" + Партньорска програма

**Бутонът на сайта:**
1. В `/admin/links` попълни полето "Telegram бот (линк за 5% отстъпка бутона)" с адрес във формат:
   `https://t.me/ИМЕ_НА_БОТА?start=discount`
2. Бутонът автоматично се появява под формата за заявка на сайта. При клик отваря директно бота в Telegram и показва екрана с отстъпката — не общата група, за да няма "мазало" с всички в един чат.

**Партньорска програма (плащане на комисион):**
- Хората кандидатстват директно през бота (бутон "💼 Стани партньор") — дават име, телефон, дейност.
- Ти преглеждаш кандидатурите в `/admin/partners`, одобряваш или отказваш с бутон — ботът автоматично им праща съобщение с резултата.
- Одобрените партньори получават достъп до "Партньорски портал" в бота — изпращат клиенти (име, телефон, какво искат) директно оттам.
- Всеки изпратен клиент се появява в `/admin/partners/<партньор>` — там маркираш статус (нов/продадено/отказал) и въвеждаш сума на комисиона — ботът автоматично известява партньора.


```
app.py                    # Flask routes, логика
models.py                 # SQLAlchemy модели (Product, GalleryPost, Lead, TelegramMember, SocialLink...)
bot.py                     # опционален Telegram бот с команди /leads /stats
bot_community.py           # Telegram бот за общността с реферална програма за отстъпки
Procfile                   # команда за стартиране в Railway
templates/index.html       # публичен сайт
templates/admin/           # админ панел
static/style.css           # стилове на публичния сайт
data/                       # база данни + качени снимки (локално; на Railway това е Volume-ът)
```
